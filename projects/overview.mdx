A **project** is the shared workspace in Parle. Everything the team does for a piece of work lives inside it: conversations everyone on the project can see and continue, the project's files, a spending budget, standing instructions for the agent, and the tools it is allowed to use.

Creating one takes under a minute. The parts that make it genuinely useful — members, storage, context, budget — are set up afterwards from the project's own tabs.

<Note>
  **You'll need:** to be an **Org Admin**. Creating projects is Org Admin only; once a project exists, its **Project Admins** run it day to day.
</Note>

<Tip>
  **Worth doing first:** connect at least one AI model for your organization — see [Connecting Providers](/models/connecting-providers). A project without any enabled models can be created, but nobody will be able to chat in it.
</Tip>

## Creating a project

<Steps>
  <Step title="Open the New project form">
    Go to **Projects** and select **New project** (top right).
  </Step>
  <Step title="Name and describe it">
    - **Name** — required, e.g. `Q3 Research`. Shown on the project card and everywhere the project is referenced.
    - **Description** — optional; one line on what the project is for.
    - **Project code** — optional; your own accounting reference for the project, such as a matter number, cost centre or expense code. It appears beside the project's spend in usage reports and CSV exports. See [Expense Codes](/cost/expense-codes).
  </Step>
  <Step title="Choose visibility">
    - **Public** — anyone in your organization can open this project. Members are still used to decide who is a Project Admin.
    - **Restricted** — only people you add as members can open it. Use this for client-confidential or sensitive work.
  </Step>
  <Step title="Set a budget">
    - **Budget currency** — the currency this project's spending caps are stated in: USD, CAD, EUR or GBP. Pick the one you report this work in — **it is fixed once the project records any spend.**
    - **Cap period** — whether the amount below is a limit for **Every month** (spending resets on the 1st) or a **Total, for the life of the project**. Monthly is the default.
    - **Monthly cap** / **Total cap** — how much the project may spend over that period, in the currency above. **Set 0 for no limit** — spend is still tracked, and the project is created with no cap at all. (On the **Budget** tab afterwards, a cap is switched on or off with a tick rather than by typing 0, so a ticked cap there needs an amount above zero.)

    <Note>
      The **Budget currency** you pick here is saved together with the cap. A project created with the amount at 0 has no cap to attach it to, so it starts in **USD** whatever you picked. To use another currency, open the project's **Budget** tab and set it there **before the project records any spend** — after that it is fixed.
    </Note>

    You can change the amount later, and add the other cap, from the project's **Budget** tab. See [Budgets](/cost/budgets).
  </Step>
  <Step title="Choose available models">
    Every model your organization has enabled is ticked by default. Untick any you want to **block** for this project, for example to keep an expensive model off a high-volume project. This section only appears if your organization has models connected. After creation, blocked models and any other rules for this project live in its [model policy](/models/model-policy), on the **Budget** tab.
  </Step>
  <Step title="Choose storage">
    **Parle Cloud Storage** needs no setup and is the default. If your organization has connected SharePoint or Google Drive, you can point the project at it after creation.
  </Step>
  <Step title="Create the project">
    You land in the project's workspace, already added as its **Project Admin**.
  </Step>
</Steps>

<Warning>
  **Visibility cannot be changed from the project's tabs later — decide it now.** If you are unsure, **Restricted** is the safer choice; you can always add the whole team as members.
</Warning>

## Adding members

On a **Restricted** project the member list _is_ the access list. On a **Public** project everyone in the organization can already open it, so this mainly decides who the admins are.

<Steps>
  <Step title="Open the Members tab">
    Under **Add an org member**, pick the person.
  </Step>
  <Step title="Set their access">
    **Project Admin** — can edit project details, the context file, storage, and membership. **Project Member** — can use the project.
  </Step>
  <Step title="Optionally set a project role">
    Free text describing what they do here, e.g. `Business Analyst`. It is a label for the team, not a permission.
  </Step>
  <Step title="Select Add member">
    Repeat for everyone who needs access.
  </Step>
</Steps>

Change someone's access or role directly in the roster, or **Remove** them. Every project must keep **at least one Project Admin** — removing the last one is refused.

<Note>
  People must already be members of your organization before they can be added to a project. See [Managing Members](/admin/managing-members).
</Note>

## Pointing the project at storage

Every project has a file area the team and the agent both use. By default that is Parle-managed storage, which works immediately. If your organization has connected SharePoint or Google Drive, you can instead root the project in a document library or Shared Drive so files stay in your own tenant.

<Steps>
  <Step title="Open Project Details → Storage">
    Choose a provider.
  </Step>
  <Step title="Parle Cloud Storage">
    Managed storage, no setup.
  </Step>
  <Step title="SharePoint">
    Paste the **site URL** (e.g. `https://contoso.sharepoint.com/sites/Marketing`) and select **Resolve**, choose a **document library**, and optionally a **folder** within it to root the project at.
  </Step>
  <Step title="Google Drive">
    Paste the URL of the **Shared Drive itself** — its root, not a sub-folder inside it.
  </Step>
  <Step title="Save storage">
    Parle checks it can actually reach the location before saving, so a permissions gap is caught now.
  </Step>
</Steps>

SharePoint and Google Drive only appear if an Org Admin has enabled them for your organization, and each needs its own tenant-side permission grant first — see [Connect Microsoft 365](/admin/microsoft-365) and [Connect Google Workspace](/admin/google-workspace).

## Project context (`agent.md`)

`agent.md` holds standing instructions for the agent — the equivalent of a project brief, injected at the start of **every conversation in the project**. This is the single highest-leverage thing you can set up on a new project. See [Shared Context](/projects/shared-context).

## Enabling tools

If your organization has connected integrations, open the **Tools** tab and switch on the ones this project should have. Nothing is enabled by default — an integration is available to a project only once it is toggled on there. See [Integrations](/tools/integrations).

## Archiving and restoring a project

When a project is finished, an Org Admin can archive it instead of leaving it in the active list. Archiving is **Org Admin only** — a Project Admin can see the control but cannot use it.

<Warning>
  **Archiving permanently deletes the project's knowledge sources and integration connections.** Restoring the project later brings the project itself back, but **not** that deleted data. Conversations and files are not affected either way — archiving and restoring never touch them.
</Warning>

<Steps>
  <Step title="Open Project Details → Danger Zone">
    Scroll to the bottom of the project's **Details** tab.
  </Step>
  <Step title="Select Archive">
    Type the project's name exactly to confirm, then select **Archive project**. This extra step exists because the data loss above is real and cannot be undone by restoring.
  </Step>
</Steps>

An archived project:

- Stops counting against your subscription's project limit.
- Drops off everyone's **Pinned** list (their pin is kept and reappears automatically if the project is restored).
- Stays fully readable — anyone who could open it before can still open it, browse its conversations, and read its files.
- Loses team access to any Microsoft 365 or Google Workspace integrations it had connected, and every knowledge source it owned — both are deleted, not paused.

To restore one, go to the **Projects** page and open the collapsed **Archived** section at the bottom of the list. Each archived project's card has a **Restore** button — a single confirm click, since restoring destroys nothing.

## Troubleshooting

| Symptom | Likely cause | Fix |
| --- | --- | --- |
| No **New project** button | You are not an Org Admin | Project creation is Org Admin only — ask one to create it and make you a Project Admin |
| "Project limit reached: your plan allows N projects" | Your subscription tier caps active projects | [Archive](#archiving-and-restoring-a-project) a project you have finished, or upgrade the plan |
| "Private (Restricted) projects require the Business plan or above" | Restricted visibility is not available on your tier | Create it as Public, or upgrade |
| "Your subscription is not active" | Subscription incomplete, unpaid, or cancelled | Complete or update the subscription in Org settings → Organization → Current plan |
| Creating the project is refused: "Parle can't currently price budgets in EUR, so this budget can't be saved yet…" | You chose a **Budget currency** other than USD and typed a cap, and Parle has not published an exchange rate for that currency yet — a Parle issue, not yours. Despite the wording, it is the whole project that was not created, not just its budget | Try again shortly. To get started straight away, create the project with the cap amount at 0 — it is created in USD with no cap — then set the currency and caps on its **Budget** tab once rates are available. Do that **before the project records any spend**, because the budget currency is fixed from the first spend |
| No **Available models** section on the form | Your organization has not connected any model providers | [Connect a provider key](/models/connecting-providers) first |
| Nobody can chat in the new project | No models enabled, or the project's model policy leaves none usable | Check the project's [model policy](/models/model-policy) on the **Budget** tab, then the organization's enabled models and policy |
| A message is refused: an admin has restricted this model | The organization's or project's [model policy](/models/model-policy) doesn't allow that model | Select **Continue with …** to resend on an allowed model, or ask an admin to change the policy |
| A message is refused for its cost, not the budget | It is over the [per-message spending limit](/models/model-policy#per-message-spending-limit) | Compact the conversation or start a new one, or select **Request a higher limit** |
| SharePoint or Google Drive not offered under Storage | The provider is not enabled for your organization | An Org Admin enables it in Org settings → Files & search → File storage |
| Saving storage fails a connectivity check | Parle has not been granted access to that site or Shared Drive | Grant access on the provider's side first, then save again |
| Someone cannot open the project | It is **Restricted** and they are not a member | Add them on the **Members** tab |
| Cannot find someone in the add-member list | They are not in your organization yet, are deactivated, or are already on the project | Invite them to the organization first |
| **Remove** refused on the last admin | Every project needs at least one Project Admin | Promote someone else first, then remove |
| Messages blocked: "This project's monthly cap of … has been reached" (or lifetime cap) | Spend reached one of the project's caps | Select **Request a higher limit**, or have an Org Admin raise the cap on the **Budget** tab. A monthly cap also resets on the 1st |
| **Budget currency** cannot be changed | The project has already recorded spend | The currency is fixed from the first spend — see [Budgets](/cost/budgets#why-the-budget-currency-locks) |
| Project details are read-only | You are not a Project Admin on this project | Ask a Project Admin or Org Admin to make the change, or to promote you |

Still stuck? Contact Parle support with your organization name and the project name.
